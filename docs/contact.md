# Contact

A question about a library, a bug to report, or simply a word? Here is where to write.

## About a library

Open an issue on the repository of the library. It is the fastest way, and it leaves a trace others can
find: a question asked in the open has often already been answered there. The libraries live on the
[Spomky-Labs](https://github.com/Spomky-Labs) organization, and those of
[web-auth](https://github.com/web-auth) and [web-token](https://github.com/web-token) on theirs.

A security problem is never reported in a public issue. Each repository describes how to report one in
its security policy, `SECURITY.md`, under the Security tab.

## For anything else

Write to [bonjour@spomky-labs.com](mailto:bonjour@spomky-labs.com).

You can also reach me on [GitHub](https://github.com/Spomky), [X](https://twitter.com/spomkylabs) and
[Mastodon](https://framapiaf.org/@spomky).
