    The IANA registry¶

    Tag numbers are held in the CBOR tags registry of IANA. The library implements the ones below, and registers all of them in the decoder by default. The registry is open ended, and most of what is missing from the table is specific to one application: any other number still decodes, as a tag that keeps its number without interpreting it.

    Every class is in the CBOR\Tag namespace, the typed arrays in CBOR\Tag\TypedArray. The tags of RFC 8949 itself are described in the built-in tags, the others in more tags of the registry.

    A tag the library does not know¶

    A tag number no class is registered for is not an error: the decoder returns a GenericTag, which keeps the head and the object the tag wrapped, so a document survives a round trip through code that does not understand all of it. Its normalize() normalizes the wrapped item on its own, since the number carries no meaning the library knows.

    GenericTag::getTagId() returns -1, because the class stands for no number in particular. The number itself is in the head of the item: it is the additional information when that is 23 or less, and the big-endian payload getData() returns otherwise.

    use CBOR\CBORObject;
use CBOR\Tag\GenericTag;

function tagNumberOf(GenericTag $tag): int
{
    $ai = $tag->getAdditionalInformation();
    if ($ai <= 23) {
        return $ai;
    }

    $data = (string) $tag->getData();

    return match ($ai) {
        CBORObject::LENGTH_1_BYTE => ord($data),
        CBORObject::LENGTH_2_BYTES => unpack('n', $data)[1],
        CBORObject::LENGTH_4_BYTES => unpack('N', $data)[1],
        CBORObject::LENGTH_8_BYTES => unpack('J', $data)[1],
    };
}

$decoded = $decoder->decode(StringStream::create(hex2bin('d904d201')));

$decoded instanceof GenericTag;   // true
tagNumberOf($decoded);            // 1234
$decoded->getValue();             // UnsignedIntegerObject, the tagged item

    When a number matters to your application, give it a class of its own — writing a tag of your own — and register that class with the decoder. The decoder then hands you that class instead of a GenericTag, and getTagId() answers properly.
